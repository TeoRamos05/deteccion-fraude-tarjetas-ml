# Datos (no incluidos)

Los conjuntos de datos no se redistribuyen en este repositorio. Descárgalos desde Kaggle (requiere cuenta) y colócalos así:

## ULB: Credit Card Fraud Detection
- Ruta: `data/ulb/creditcard.csv`
- Fuente: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud (versión 3 de Kaggle, última actualización 23/03/2018).
- Licencia indicada en Kaggle: base de datos bajo ODbL 1.0 y contenidos bajo DbCL 1.0.
- Procedencia: colaboración de Worldline y el Machine Learning Group de la Université Libre de Bruxelles (ULB). Cita los trabajos que
  Kaggle pide citar en la sección de reconocimientos de la página.
- La moneda de `Amount` no está documentada.
- Datos descargados en este proyecto el 06/10/2026 (fecha de los archivos locales).

## IEEE-CIS: Fraud Detection
- Rutas: `data/ieee_cis/train_transaction.csv` y `data/ieee_cis/train_identity.csv`
- Fuente: https://www.kaggle.com/c/ieee-fraud-detection (licencia en Kaggle: "Subject to Competition Rules").
- Las reglas de la competencia permiten el uso no comercial, incluida la investigación académica, y prohíben transmitir, duplicar,
  publicar o redistribuir los datos. Por eso este repositorio no los incluye ni publica las predicciones de IEEE-CIS.
  Lee las reglas vigentes antes de usar los datos: https://www.kaggle.com/competitions/ieee-fraud-detection/rules
- Datos descargados en este proyecto el 06/10/2026 (fecha de los archivos locales).
